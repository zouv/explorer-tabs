# ExplorerTabHost 技术栈

C#、WinForms、.NET Framework 4.8、x64；使用本机 Win32 / Shell COM，无第三方 NuGet 依赖。
Windows 10 Explorer 原窗口常驻，SetParent 嵌入或分组显隐。不是单文件视图的目录导航，不注入 Explorer。
模板的 Python / uv 脚手架不适用，采用既有 sln / csproj 和 PowerShell 构建，manager.sh 为 Git Bash 命令入口。
跨进程挂载存在焦点 / DPI / Shell 兼容边界；正常退出必须分离。不会复制 QTTabBar GPL 源码。
