# Windows 10 真实 Explorer 手动验收

当前自动验证没有接管用户的现有 Explorer。以下条目全部仍需人工验收，不应把透明测试窗口成功等同于 Shell 兼容性成功。

## 第一轮：只用普通本地文件夹

- [x] 先关闭 QTTabBar / 其他工具的自动窗口捕获；打开两个新 Explorer 测试窗口。
- [x] 窗口 A 打开本地文件夹，在列表中滚到中间，选中一个文件；窗口 B 打开另一文件夹。
- [x] 启动 ExplorerTabHost，嵌入 A、B。检查地址栏、Ribbon、目录树、文件列表均仍可用。
- [x] 切换十次，确认 A 的路径、选择、滚动和 Explorer 自身导航历史保留。
- [x] 确认切换不新增 / 关闭窗口、不触发文件夹重新导航；观察背景空白及闪烁。
- [x] 点击文件区后测试地址栏 Ctrl+L、中文输入法、F2 重命名、Backspace / Alt+Left、复制粘贴。
- [x] 拖动外壳、调整尺寸、最大化 / 还原、最小化 / 还原；确认内容尺寸、显隐正常。
- [x] 标签右键分离 A；确认恢复接管前的大小、位置、显隐及最大化状态，且原文件现场仍在。

  测试反馈：恢复窗口后，Explorer 任务栏上看不到恢复的窗口，实际在桌面能看到该窗口（鼠标点击一下这个窗口后，Explorer 任务栏窗口缩略图上就能看到了）
- [x] “恢复并退出”；确认 B 成为独立窗口，任务栏和 Alt+Tab 可用。

  测试反馈：恢复了Explorer窗口，但任务栏 Explorer 缩略图没有立即识别到

原型没有关闭标签功能，中键表示分离，不是关闭窗口。全局 Ctrl+Tab 尚未实现。

## 第二轮：Shell 特性

每种挂载模式都测试；若嵌入有问题，先分离全部，再切到顶层分组，不在故障现场强行改模式。

- [x] 文件右键菜单、文件夹空白右键、属性 / 重命名对话框。
- [x] 文件拖放到桌面、另一个 Explorer、外部程序；包含取消拖放。
- [x] 搜索框、库、“此电脑”、回收站、压缩文件夹、网络路径。
- [x] 长耗时目录、缩略图载入、离线网络目录；记录是否阻塞宿主。
- [ ] 非活动窗口自行关闭；监控清除标签，绝不操作新的同值 HWND。
- [x] 宿主“加入窗口”及错误对话框不会被顶层分组窗口遮挡。
- [ ] 在宿主和其他程序之间切换；程序不在后台定时抢前台 / z-order。

## 第三轮：多屏 / DPI

- [ ] 100% / 150% 缩放不同显示器之间移动宿主。
- [ ] 接管前 Explorer 分别位于不同 DPI 显示器；记录 awareness context 和字号。
- [ ] 存在 awareness context 不匹配窗口时，嵌入被安全拒绝，原窗口未变化。
- [ ] 接管原先最大化、最小化的窗口；分离恢复其原状态。
- [ ] 接管原来位于主屏左侧（负坐标）的窗口；分离的位置正确。

## 崩溃 / 強杀：仅虚拟机或可牺牲测试窗口

强杀前明确没有未完成的文件操作。不要在重要工作窗口上测试。

- [x] 嵌入后强杀宿主，记录 Explorer HWND / 进程是否存活。

  测试反馈：Explorer 也 都自动关闭了，符合预期
- [ ] 重启宿主，恢复日志只能恢复仍存活的原窗口；已销毁窗口不得声称救回。
  - [ ] 测试反馈：（嵌入窗口模式）强关ExplorerTabHost.exe后重启有提示是否恢复，我点了“是”，但没有恢复
- [x] 顶层分组后强杀宿主，重启并同意恢复；检查隐藏窗口能否重新显示及恢复位置。
- [ ] 注入恢复失败或限制日志写入：记录保留、正常退出被阻止、恢复可重试。
- [x] 出现不可接受的窗口销毁 / Shell 问题时，将默认模式改为顶层分组，停止扩大嵌入范围。
