# ExplorerTabHost 使用说明

当前工程：D:/Git/zgithub/explorer_tab_host。
运行：手动启动 dist/v0.4.1-release/ExplorerTabHost.exe，显式选择加入窗口；正常退出先分离。
新建 / Ctrl+T 使用设置中的普通目录；复制标签复制当前普通目录，不复制选中项 / 导航历史。
虚拟目录（如快速访问）不按标题猜测。创建失败保留现有标签，不自动关闭独立窗口。

构建：powershell -ExecutionPolicy Bypass -File scripts/build.ps1。
安全完整验证追加：-NativeSmoke -CrossProcessSmoke -TabUiSmoke -CreationUiSmoke。
Git Bash 入口：bash manager.sh build / test / check-docs；run 仅由用户主动执行。
日志：%LOCALAPPDATA%/ExplorerTabHost/host.log；恢复：recovery.json；设置：settings.json。
有未恢复条目时不得删除 recovery.json。日志含路径，分享前检查敏感信息。
旧工程及版本仍在原目录作为备份，不再修改；人工反馈直接在对话收集。
