# ExplorerTabs 使用说明

当前工程：D:/Git/zgithub/explorer-tabs。
运行：手动启动 dist/release/unpack/ExplorerTabs.exe（由 package.bat 产出），显式选择加入窗口；正常退出先分离。
打包：package.bat 或 bash manager.sh package；历史 dist/vX-release 目录原样保留。
新建 / Ctrl+T 使用设置中的普通目录；复制标签复制当前普通目录，不复制选中项 / 导航历史。
虚拟目录（如快速访问）不按标题猜测。创建失败保留现有标签，不自动关闭独立窗口。

构建：powershell -ExecutionPolicy Bypass -File scripts/build.ps1。
安全完整验证追加：-NativeSmoke -CrossProcessSmoke -TabUiSmoke -CreationUiSmoke -WorkspaceUiSmoke。
Git Bash 入口：bash manager.sh build / test / package / check-docs；run 仅由用户主动执行。
日志：%LOCALAPPDATA%/ExplorerTabHost/host.log；恢复：recovery.json；设置：settings.json；会话库：workspace.json。
有未恢复条目时不得删除 recovery.json。日志含路径，分享前检查敏感信息。
旧备份工程仍在原目录；历史发布随仓库移动但原文件内容不变，不再修改；人工反馈直接在对话收集。

0.6.2 改名后继续使用旧数据目录与单实例标识，不迁移 / 覆盖原数据；历史发布包随仓库移动但保留原文件名与内容。
